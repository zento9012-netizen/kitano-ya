# 北の屋 写真素材

このフォルダには、店舗から正式に提供・使用許可を得た写真だけを配置します。

推奨ファイル名：
- `hero.jpg` — ファーストビュー
- `menu-kitano.jpg` — 北の定食
- `menu-mini.jpg` — ミニ北の定食
- `menu-kaki-kara.jpg` — かきカラ定食
- `shop-exterior.jpg` — 外観
- `shop-interior.jpg` — 店内
- `gallery-01.jpg`〜`gallery-06.jpg` — ギャラリー

写真が入った後は、HTML側の画像参照をこのフォルダへ切り替えるだけで運用できます。

※第三者サイトから無断転載した画像は使用しません。
